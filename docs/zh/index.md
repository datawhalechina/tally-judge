# ✨ 简介 { #introduction }

Ragas 帮助你为 AI 应用建立系统化的评估闭环。它提供一套用于评估大语言模型（LLM）应用的工具，让评估从凭感觉判断走向有据可依。

## 为什么选择 Ragas？ { #why-ragas }

传统评估指标难以衡量 LLM 应用真正关心的质量，人工评估也难以规模化。Ragas 将 **LLM 驱动的评估指标**与**系统化实验**结合起来，形成持续改进的闭环。

### 主要功能 { #key-features }

- **以实验为中心**。使用 `experiments` 以一致的方式评估改动。修改应用、运行评估、观察结果，再通过迭代持续改进 LLM 应用。

- **Ragas 评估指标**。通过简单的装饰器，为具体场景创建自定义指标，也可以使用[现有指标](concepts/metrics/available_metrics/index.md)。进一步了解 [Ragas 的指标体系](concepts/metrics/overview/index.md)。

- **易于集成**。内置数据集管理与结果跟踪功能，并支持 LangChain、LlamaIndex 等常用框架。
