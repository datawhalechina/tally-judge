## **📚 博客与见解** { #blog-insights }

阅读由社区成员撰写、面向社区的文章、教程和实践分享。

- [Luka Panić](https://www.linkedin.com/in/luka-pani%C4%87-20b671277/) 分享了以下实践。
    - [深入理解 Ragas 评估 | PIXION 博客](https://pixion.co/blog/ragas-evaluation-in-depth-insights)，详细介绍指标及其计算方法。
    - [RAG 实践中的测试集生成 | PIXION 博客](https://pixion.co/blog/rag-in-practice-test-set-generation)，介绍如何使用 Ragas 生成测试集。
- [Shanthi Vardhan](https://www.linkedin.com/in/shanthivardhan/) 分享了 [Atomicwork 如何使用 Ragas](https://www.atomicwork.com/blog/ragas-improving-atom-accuracy)，提高 AI 系统识别和检索信息的准确性，改善服务管理。
- [Pinecone](https://pinecone.io/blog) 在[“RAG 让 LLM 更强，也让不同模型趋于接近”](https://www.pinecone.io/blog/rag-study/)中使用 Ragas 研究上下文检索对 LLM 的提升。研究显示，即使数据规模增长到 10 亿，检索仍能明显改善结果。
- [Aishwarya Prabhat](https://www.linkedin.com/in/aishwaryaprabhat/) 在[使用 AzureML、LlamaIndex 和 Ragas 执行、评估与跟踪高级 RAG](https://www.linkedin.com/pulse/performing-evaluating-tracking-advanced-rag-ft-azureml-prabhat-i1rkc/)中分享了高级 RAG 技术。
- Leonie（[@helloiamleonie](https://twitter.com/helloiamleonie?source=about_page-------------------------------------)）在[使用 RAGAs 评估 RAG 应用](https://towardsdatascience.com/evaluating-rag-applications-with-ragas-81d67b0ee31a)中详细介绍了她的经验。
- [Erika Cardenas](https://twitter.com/ecardenas300) 与 [Connor Shorten](https://twitter.com/CShorten30) 合作撰写了 [RAG 评估概览 | Weaviate](https://weaviate.io/blog/rag-evaluation)，并与 Ragas 团队录制了播客。
- [Erika Cardenas](https://twitter.com/ecardenas300) 通过 Ragas 调整 Weaviate 的 alpha 参数，探索[混合检索权重对 RAG 表现的影响](https://www.linkedin.com/posts/erikacardenas300_i-tested-the-rag-performance-of-hybrid-search-activity-7139679925426376705-TVtc?utm_source=share&utm_medium=member_desktop)。
- [LangChain](https://blog.langchain.dev/) 的[使用 RAGAs 与 LangSmith 评估 RAG 流水线](https://blog.langchain.dev/evaluating-rag-pipelines-with-ragas-langsmith/)完整介绍了如何结合两种工具开展评估。
- [Plaban Nayak](https://nayakpplaban.medium.com/) 在[使用 RAGAS 评估 RAG 流水线](https://medium.aiplanet.com/evaluate-rag-pipeline-using-ragas-fbdd8dd466c1)中，演示如何通过 LangChain 和 RAGAS 构建、评估简单的 RAG。
- [Stephen Kurniawan](https://www.linkedin.com/in/stepkurniawan/) 比较了 [RAG 分块大小](https://medium.com/@stepkurniawan/rag-chunk-size-experiment-e5e5ca437f44)、[FAISS 与 ChromaDB 向量库](https://medium.com/@stepkurniawan/comparing-faiss-with-chroma-vector-stores-0953e1e619eb)、[多文档检索](https://medium.com/@stepkurniawan/comparing-faiss-vs-chroma-vector-store-retrieve-multiple-documents-07ad81a18851)，以及[相似度搜索、距离度量与索引策略](https://medium.com/@stepkurniawan/comparing-similarity-searches-distance-metrics-in-vector-stores-rag-model-f0b3f7532d6f)。
- [Devanshu Brahmbhatt](https://www.linkedin.com/in/devanshubrahmbhatt/) 在[通过 RAGAS 提升 LLM 准确率](https://devanshus-organization.gitbook.io/llm-testing-ragas)中介绍了 RAG 架构、关键指标，以及如何利用 RAGAS 得分改善系统表现。
- [Suzuki](https://www.linkedin.com/in/hirokazu-suzuki-206245110/) 与 [Hwang](https://www.linkedin.com/in/hwang-yongtae/) 使用内容相同的日语和英语数据集，比较人工标注与 Ragas 得分的相关系数，研究其表现是否受语言影响，并撰文介绍实验结果与 Ragas 基本算法。
    - [RAG 评估的必要性与挑战](https://tech.beatrust.com/entry/2024/05/02/RAG_Evaluation%3A_Necessity_and_Challenge)
    - [RAG 评估指标与 Ragas 的计算方法](https://tech.beatrust.com/entry/2024/05/02/RAG_Evaluation_%3A_Computational_Metrics_in_RAG_and_Calculation_Methods_in_Ragas)
    - [评估 Ragas 的实用性](https://tech.beatrust.com/entry/2024/05/02/RAG_Evaluation%3A_Assessing_the_Usefulness_of_Ragas)
- [Atita Arora](https://www.linkedin.com/in/atitaarora/) 在[使用 RAGAS 评估检索增强生成](https://superlinked.com/vectorhub/articles/retrieval-augmented-generation-eval-qdrant-ragas)中，端到端介绍了如何结合 [Qdrant](https://qdrant.tech/) 与 [LangChain](https://www.langchain.com/) 构建 RAG，并使用 RAGAS 评估。
    - *补充内容*，包括创建评估数据集、理解 RAGAS 指标，并将其用于简单 RAG 流水线的性能测试。
    - *代码讲解*：[Qdrant RAG 评估示例](https://github.com/qdrant/qdrant-rag-eval/tree/master/workshop-rag-eval-qdrant-ragas)
    - *结合 [Deepset Haystack](https://haystack.deepset.ai/) 和 [Mixedbread.ai](https://www.mixedbread.ai/) 的代码讲解*：[Haystack 示例](https://github.com/qdrant/qdrant-rag-eval/tree/master/workshop-rag-eval-qdrant-ragas-haystack)
- [Minoru Onda](https://x.com/minorun365) 面向初学者，介绍如何使用 Amazon Bedrock 开始 Ragas v0.2 评估，并集成 Langfuse。
    - [使用 AWS Bedrock 入门 Ragas（支持 v0.2）| Qiita](https://qiita.com/minorun365/items/2f4e238f8bbc6e393ba5)
    - [用 Ragas 评估生成式 AI 输出，并在 Langfuse 中可视化监控 | Qiita](https://qiita.com/minorun365/items/70ad2f5a0afaac6e5cb9)
- [Yunnglin](https://github.com/Yunnglin) 介绍了如何将 Ragas v0.2 集成到大模型评估框架 [EvalScope](https://github.com/modelscope/eval-scope)，接入 [ModelScope](https://github.com/modelscope/modelscope) 生态。
    - 英文教程：[在 EvalScope 中使用 Ragas](https://evalscope.readthedocs.io/en/latest/user_guides/backend/rageval_backend/ragas.html)
    - 教程: [在EvalScope中使用Ragas一键发起RAG评估](https://evalscope.readthedocs.io/zh-cn/latest/user_guides/backend/rageval_backend/ragas.html)
    - 最佳实践: [打破文本边界：如何进行多模态RAG评估](https://evalscope.readthedocs.io/zh-cn/latest/blog/RAG/multimodal_RAG.html#multimodal-rag)
