# 集成 { #integrations }

Ragas 可以与多种框架和工具集成，
方便你在现有工具链中使用。如果尚未支持所需工具，
欢迎提交 [issue](https://github.com/vibrantlabsai/ragas/issues/new)，
我们会进一步了解需求。🙂


## 框架 { #frameworks }

- [Amazon Bedrock](amazon_bedrock.md)，用于构建、部署和扩展智能体及集成 AI 方案的托管服务，详情见[官网](https://aws.amazon.com/bedrock/)。
- [Haystack](haystack.md)，构建可定制、适用于生产环境的 LLM 应用的编排框架，详情见[官网](https://haystack.deepset.ai/)。
- [Griptape](griptape.md)，通过灵活的 LLM、RAG 等抽象简化生成式 AI 应用开发，详情见[文档](https://docs.griptape.ai/stable/griptape-framework/)。
- [LangChain](langchain.md)，用于构建 LLM 应用的框架，详情见[官网](https://www.langchain.com/)。
- [LlamaIndex RAG](_llamaindex.md)，用于构建 RAG 应用，详情见[官网](https://www.llamaindex.ai/)。
- [LlamaIndex 智能体](llamaindex_agents.md)，构建具有一定自主性的智能体，详情见[官网](https://www.llamaindex.ai/)。
- [LlamaStack](llama_stack.md)，Meta 提供的统一框架，支持在本地、云端和移动端构建与部署生成式 AI 应用，详情见[文档](https://llama-stack.readthedocs.io/en/latest/)。
- [OCI Gen AI](oci_genai.md)，Oracle Cloud Infrastructure 生成式 AI 服务，提供 Cohere、Meta 和 Mistral 等模型用于 RAG 评估。
- [R2R](r2r.md)，具备生产功能的一体化 RAG 方案，详情见[文档](https://r2r-docs.sciphi.ai/introduction)。
- [Swarm](swarm_agent_evaluation.md)，用于编排多个 AI 智能体的框架，详情见[仓库](https://github.com/openai/swarm)。

## 追踪工具 { #tracing-tools }

将 LLM 调用追踪工具集成到 Ragas，可以查看评估模型的执行记录。

- [Arize Phoenix](_arize.md)，LLM 可观测性与调试平台，详情见[官网](https://phoenix.arize.com/)。
- [LangSmith](langsmith.md)，LangChain 提供的 LLM 可观测性与调试平台，详情见[官网](https://www.langchain.com/langsmith)。
