# 测试集生成 { #testset-generation }

高质量的测试数据集是评估 AI 应用性能的基础。

## 理想测试数据集的特征 { #characteristics-of-an-ideal-test-dataset }

- 数据样本质量高
- 覆盖真实环境中可能出现的多种场景
- 样本量足以支持具有统计显著性的结论
- 持续更新，以应对数据漂移

手动构建这样的数据集往往耗时且成本高。Ragas 提供一套工具，用于生成评估 AI 应用所需的合成测试数据集。
